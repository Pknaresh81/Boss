License Activation
Apna valid license key enter karein.
Iske baad **Electron completely restart** karein — sirf license window close/open nahi, poora app restart. Phir **Ctrl + Shift + I → Console** mein sabse pehle ye 3 lines dekhein: ```text [LICENSE HTML] Script loaded [LICENSE HTML] electronAPI: ... [LICENSE HTML] verifyLicenseKey: ... ``` Activate dabane ke baad: ```text [LICENSE HTML] Activate clicked [LICENSE HTML] Calling IPC... ``` Aur agar IPC sahi connected hai to terminal mein: ```text [LICENSE] Verification request received: YOUR_KEY [LICENSE] Calling verifyLicense()... ``` aana chahiye. **Agar ab bhi terminal mein `[LICENSE] Verification request received` nahi aata, to next mujhe DevTools Console ka poora output bhej dena.**
